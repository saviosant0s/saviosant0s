## Em destaque

### 🏰 [Castelei](https://github.com/saviosant0s/castelei) · em desenvolvimento

Plataforma de estudos que ensina o conteúdo **e** a linguagem da prova: lições em etapas, uma ideia por tela, e treino cronometrado em Modo Prova. A revisão se agenda sozinha conforme a data da prova se aproxima.

- 6 matérias, 83 lições e 650 questões originais em quatro formatos
- Verificador automático de conteúdo que roda no CI como se fosse teste
- 267 testes no backend (PHPUnit) e 337 no frontend (Vitest)
- **App no ar:** [frontend-production-3c7da.up.railway.app](https://frontend-production-3c7da.up.railway.app) (entra sem cadastro)

`Laravel 12` `Next.js 16` `React 19` `Tailwind 4` `PWA`

### 🏁 [Number Race](https://github.com/saviosant0s/Numberrace) · projeto de pesquisa no IFBA

Contribuição para o Number Race, jogo educacional de matemática para crianças (Java), em projeto orientado pelo prof. Edeyson Andrade Gomes. Desenvolvi o **componente de registro e exportação dos dados de interação** do jogo.

- Modelo de eventos com 23 tipos, descrito em JSON Schema
- Gravação em JSON Lines (fonte da verdade) + SQLite, sem travar o jogo se o disco falhar
- Exportação para CSV, Excel e SQLite com manifesto SHA-256 e verificador de integridade (21 regras)
- 100 testes automatizados (JUnit), tudo validado só com dados simulados
- Correção de dois defeitos de áudio do jogo legado
- Trabalho entregue por Pull Requests ao repositório do orientador ([eduknowgpt/Numberrace](https://github.com/eduknowgpt/Numberrace/pulls?q=is%3Apr+author%3Asaviosant0s))

`Java 8` `Maven` `SQLite` `JSON Schema` `JUnit`

### 🍬 [Doce Texto Quiz](https://github.com/saviosant0s/Doce-Texto-Quiz) · projeto de 2023, sendo refeito

Quiz sobre Word e Excel criado em 2023 por alunos do IFBA Campus Valença, agora refeito no Godot 4: 3 níveis, combos, ajudas com moedas, revisão dos erros, conquistas e uma coleção de doces em 3D montados por código.

- **Jogar no navegador:** [saviosant0s.github.io/Doce-Texto-Quiz](https://saviosant0s.github.io/Doce-Texto-Quiz/)

`Godot 4` `GDScript`
